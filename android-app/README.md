# MobileHarness

📖 **[中文使用指南](../README.md) · [English user guide](../README.en.md)**

在手机上交给 GUI Agent 执行任务，按需接管、自由操作，再归还控制。支持独立模型配置、可选 Harness，以及本地实验记录和分析。

Run tasks with a GUI Agent on your phone. Take over when needed, act freely, and return control. Includes separate model configurations, optional Harness, and local experiment records and analysis.
