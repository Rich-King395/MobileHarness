## 🇨🇳 开始使用

1. 下载 APK，按系统提示允许当前浏览器或文件管理器安装此来源的应用。[Android 安装说明](https://developer.android.com/distribute/marketing-tools/alternative-distribution)
2. 打开 **MobileHarness（正式版）**，手动开启其无障碍服务，允许通知作为备用控制入口。Android 13 及以上若提示“受限设置”，在确认信任本项目后，按设备提示进入该 App 信息页允许受限设置，再开启服务；菜单随设备而异。[Android 官方说明](https://support.google.com/android/answer/12623953?hl=zh-Hans)
3. 在“模型”页添加自己的兼容服务地址、模型名称和 API Key，分别选择 GUI Agent 与 Planner；当前主要验证 **Qwen 3.8 MAX**。将配置命名为 GPT 或 Claude 不会自动提供原生 API 支持。
4. 选择允许操作的 App，输入任务，确认必要截图会发送至所选远端模型服务后开始。默认 GUI 额度为 30 步，可选择开启 Harness。
5. 通过悬浮入口接管，等待显示“人工”后操作手机，再归还控制；也可随时中止。每个任务支持一次有效接管与归还，人工操作不扣步数或重置额度。

功能包括手机独立运行、多份模型配置、可选恢复规划、本地加密任务记录及用量分析、中英双语。运行推理需要联网和你自己的模型服务，安装包不附带 API Key。

正式版可与开发版并存，配置和记录独立保存；只开启一个版本的无障碍服务。已有开发数据保留在原包，不自动迁移到正式版。截图仅按当前推理需要在内存暂存；人工控制期间不采集画面或操作轨迹。

**测试范围：**同版本正式构建已在 Pixel 4 / Android 13 验证安装、启动和双包并存；开发版已有用户报告任务执行、接管与归还后继续成功。正式版完整模型流程、跨版本升级及其他手机仍待验证。自动检查覆盖 JVM、Python 测试与冻结提示词，详见[检查结果](https://github.com/Rich-King395/MobileHarness/actions/workflows/android-ci.yml)；附件元数据区分本包与先前构建的设备证据。本版本为 Beta，尚非完成多设备验收的 User Study 发布基线；模型声明结束与任务成功分别记录。

## 🇬🇧 Get started

1. Download the APK and follow Android's prompt to allow installs from the browser or file manager you use. [Android installation guidance](https://developer.android.com/distribute/marketing-tools/alternative-distribution)
2. Open **MobileHarness (Release)**, manually enable its accessibility service, and allow notifications for the backup controls. On Android 13+, if Android blocks access as a restricted setting, review whether you trust this project and follow your device's App info prompts before enabling the service. Menus vary by device. [Android guidance](https://support.google.com/android/answer/12623953?hl=en)
3. Add your own compatible endpoint, model name and API Key on the Models page; select profiles for the GUI Agent and Planner. **Qwen 3.8 MAX** is the main validated model. Naming a profile GPT or Claude does not add native API support.
4. Select authorized Apps, enter a task, and acknowledge that necessary screenshots are sent to your selected remote model services. The default GUI budget is 30 steps; Harness is optional.
5. Request takeover from the floating control, wait for **Manual**, operate the phone, then return control. Use Stop to end the task. Each task supports one effective takeover and return; manual actions do not consume or reset the budget.

Features include phone-only operation, multiple model profiles, optional recovery planning, encrypted local task records and usage analysis, and Chinese/English UI. Remote inference requires internet access and your own model service; no API Key is included.

Release and development versions can coexist with separate profiles and records. Enable only one version's accessibility service at a time. Existing development data stays in its original app and is not migrated automatically. Screenshots are held in memory only as needed for inference; no screens or action traces are collected during manual control.

**Validation scope:** a release build of this version passed installation, startup and coexistence checks on Pixel 4 / Android 13. Users reported successful tasks and takeover/return on the development version. Full model-driven release flows, version upgrades and other phones await validation. Automated checks cover JVM/Python tests and frozen prompts; see [CI](https://github.com/Rich-King395/MobileHarness/actions/workflows/android-ci.yml). Asset metadata distinguishes device evidence for this APK from earlier builds. This is a beta, not a completed multi-device User Study release baseline. A model's finish declaration is recorded separately from task success.
