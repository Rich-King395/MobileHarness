# APK 验收范围与故障归因

确认日期：2026-10-31。依据用户本轮明确要求：MobileHarness 负责稳定可靠地调用模型、传递允许的信息、按约定执行模型动作；提高模型自身的推理、规划或任务成功能力不属于当前 APK 开发目标。

## 分开记录的四类结果

| 结果层 | 检查内容 | 不能由它推出的结论 |
| --- | --- | --- |
| 模型服务／协议 | 地址、鉴权、请求参数、响应解析、原生动作格式是否符合合同 | 合法响应不代表模型选对动作；传输／格式异常不代表推理能力差 |
| APK 流程与执行 | 请求内容、当前画面、阶段历史、坐标映射、原动作派发、输入终态、接管屏障、预算及授权是否遵守合同 | 系统手势完成不代表模型点中了任务需要的控件 |
| 可观察任务终态 | 用户或独立核验所见目标达成、未达成或未知 | 目标未达成不能自动记为 APK 故障，也不能在缺乏证据时定论为模型推理错误 |
| 原因归属 | 由哪项可复现的合同偏差造成问题 | 未发现错误事件不等于整个 APK 合同都已证明正确；单步通过不等于所有步骤正确 |

APK 只对前两层中属于客户端责任的合同负责；远端不可用或非法模型输出需要被准确呈现和处理，不要求 APK 修复模型或服务本身。业务成功评价继续独立记录，不作为 APK 技术验收的额外结束门槛。

## APK 的验收重点

1. 独立使用用户选择的 GUI／Planner 配置，按当前已确认协议发起实际请求；无隐藏重试、额外规划或坐标修正。
2. 正确传递原任务、所属阶段允许的历史、接管／归还通知与必要新观察；图像方向、尺寸和坐标约定匹配。
3. 对合法、已授权且仍有效的动作，按模型原始参数完成既定映射并派发，准确反馈原生执行状态；拒绝过期、越权、格式错误或该阶段不允许的动作。
4. 接管立即关闭后续派发与采集，屏蔽过期回复，依据真实输入终态进入人工；归还按当前设计取得新观察并切换对应路径。
5. 共享预算、两次 Planner／一轮只读上限、P2 直接结束、回退、Harness 关闭路径、隐私和本地密钥均遵守已确认合同。
6. 启动、取消、设备断开、服务异常与结束都有准确的 UI／日志反馈。不能因模型动作不明智而把合法动作悄悄改成开发者认为正确的动作。

关键路径优先使用可控模型响应、合成任务与真实执行器验收，精确复现竞争和边界。真实模型用于必要的接口兼容及少量链路 smoke；不再为提高计算题或其他任务的成功率持续运行能力试验、修改任务策略或优化模型推理提示词。

## 现有分类的含义

保持冻结事件 Schema 与当前错误码，不改写旧记录：

- `MODEL / TRANSPORT_ERROR`、`API_ERROR`、`INVALID_OUTPUT` 表示模型服务交互或协议层异常；`MODEL` 是现有技术分类标签，不是“推理错误”的判定。
- `DEVICE` 记录授权、采集、输入或设备状态问题；具体归因仍应核查是否由 APK 调用或设备条件造成。
- `COORDINATOR` 记录协调合同问题。正常的 `budget_exhausted` 是结束原因，本身不是协调器错误。
- 合法但选错的 tap／输入／规划分支仍按实际协议与执行结果记录；不因任务未完成而补写 `INVALID_OUTPUT`、`INPUT_FAILED` 或其他技术故障。
- `finish(completed)`、`finish(unable)`、用户评价和独立终态观察各自保留含义。不得自动修正结束声明或增加逐条件门槛。

当前实现对部分未分类异常会按所在处理阶段兜底归类。因此错误类别首先表示处理环节，不单独证明根因来自外部模型、网络、手机或 APK 内部；需要结合可复现的链路断言定位。`model_call.succeeded` 只表示响应通过当前适配器校验，`action.completed` 只表示执行器确认动作终态。

## 当前计算器记录的解释

R-04 的旧 `status=FAIL` 只指可观察任务终态未达成，追加明确的作用范围，不将它当作 APK 流程验收 FAIL。已观察到响应解析、计数、无额外 Planner 和额度结束等正常表现，没有记录技术错误；但该次完整请求内容、逐次坐标映射和启动触摸隔离未独立核验，因此也不能改写为 APK 全合同 PASS 或确诊模型推理错误。

R-05 仅通过一次原落点映射与实际输入效果的专项检查，不是模型能力评分，也不替代 R-04 全链路证据。后续工作回到 APK 合同、交互和功能稳定性，不以“修好模型多步计算”为开发目标。

0.1.3 的前台启动确认、失败草稿保留、键盘与状态反馈属于 APK 交互改进；它们依据代码审查和相应检查实施，不被宣称为 R-04 计算失败的原因或修复证据。原提示词、实验快照和数据边界保持不变。
