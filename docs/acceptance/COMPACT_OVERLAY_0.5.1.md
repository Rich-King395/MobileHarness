# 三组件悬浮控制：0.5.1

日期：2026-11-02。按用户要求精简悬浮控制，使用项目本地 ui-ux-pro-max 指南审查触点、颜色与状态表达。沿用原生 Android Views，不新增依赖。

## 已实现

展开后只有一行三个组件：**状态／接管或归还／中止**。默认字号为 256 × 56dp；移除了 GUI／Planner 计数、运行解释、标题和滚动详情区。状态配颜色与短文字，按钮使用统一绘制的矢量图形，不依赖 emoji 或字体符号。触点至少 48dp，组件间距 8dp。

| 运行状态 | 状态呈现 | 中间按钮 | 中止 |
| --- | --- | --- | --- |
| AUTO，尚未归还 | 绿色“运行中” | 接管 | 直接触发 STOP |
| PAUSING | 黄色“暂停中” | 灰显“等待” | 可用 |
| MANUAL | 黄色“人工” | 归还 | 可用 |
| PREPARING／CHECKING | 蓝色“准备中／查证中” | 灰显 | 可用 |
| AUTO，已归还 | 绿色“运行中” | 灰显“已归还” | 可用 |
| BLOCKED／UNCERTAIN | 黄色“已暂停／待确认” | 重试／检查 | 可用 |
| STOPPING | 红色“中止中” | 灰显 | 灰显，等待真实输入终态 |
| ENDED，模型声明完成 | 绿色勾号“完成” | 打开 | 灰显 |
| ENDED，用户中止 | 红色“已中止” | 打开 | 灰显 |
| ENDED，预算耗尽或其他结束 | 中性“已结束” | 打开 | 灰显 |
| IDLE | 中性“就绪” | 打开 | 灰显 |

“完成”对应已有模型结束声明，独立任务结果仍按原记录规则判断。实现只匹配协调器的固定结束文案，不显示或持久化任意 message。无障碍描述保留其模型结束／结果未独立核验的含义，不添加可见解释。

点击状态组件收起，仍能拖动贴边。运行中收起形态保留独立中止触点。中止不增加确认弹窗；已派发输入仍须达到真实终态，不通过 UI 假装立即终止。接管后只有真正进入 MANUAL 才允许归还，仍限制一次有效接管／归还。

字号变大时按文字测量扩展；空间不足可纵排，低矮区域优先保留中止触点并压缩前两项；连三个最小触点也无法容纳时回到收起形态。截图前完整隐藏根控件，截图后收起恢复；避让移动自家控件，不修改模型坐标。系统无障碍现在可以发现固定控件标签，本版没有进行实际 TalkBack 验收。
