## 条件

安全合成目标：从桌面打开 MobileHarness Test，点击测试按钮一次，使可见计数为 1，然后结束；不编辑、长按、保存或打开其他 App。开始前通过 fixture RESET 和固定资源 ID 确认点击 0、长按 0、输入为初始值、未保存、保存值为空。只临时授权该合成 App；原范围为空，测试后恢复。原 Harness 开启，测试保持开启，无接管，预期 Planner 0；GUI 额度临时设为 8，恢复时为原 30。

任务英文为 ASCII 输入以避免 adb 输入法对汉字的限制；没有提供屏幕坐标或动作脚本。开始按钮之后，直到阻断或结束，没有外部点击／触摸目标页；运行期间仅查看白名单元数据，没有读取目标画面或操作轨迹。截图由 APK 按合同发往配置的远端，仅临时 RAM。
