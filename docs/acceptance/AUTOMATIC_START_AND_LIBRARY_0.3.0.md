## 覆盖限制

桌面启动真机检查使用受控动作，调用真实 PhonePort；它不等于通过正常任务页进行了真实模型的端到端选择／推理实验。桌面解析和正常启动握手已有代码与布局检查，未新增商业请求来评价模型是否选对 App。

未授权归还保持 MANUAL、预算不增加、迟到结果不执行、修复后可以归还，由受控异步 JVM 场景覆盖；本轮没有要求真人重新进行接管实验。实际新手机场景、旋转、大字号、长任务和完整 37 个 Harness 主场景没有全部重跑。

全显示器截图与前台包名前后检查仅是尽力边界，不能证明没有通知／IME／瞬时覆盖窗口。图片只在 RAM，没记录图片、图片摘要、坐标或人工轨迹。本人授权范围保持未代选，首次使用需用户保存；合成测试使用独立目录和内存会话范围。
