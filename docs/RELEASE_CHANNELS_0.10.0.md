# 0.10.0 渠道与正式签名验收

日期：2026-11-03。正式渠道 `0.10.0-beta.1 / 22`，开发构建 `0.10.0-dev / 22`。本轮完成本地构建和并存安装，尚未发布 GitHub Release。维护用法见[签名与渠道](publishing/SIGNING_AND_CHANNELS.md)。

## 实现范围

- 开发身份保留 `org.mobileharness.app` 与原开发证书；正式身份为 `org.mobileharness.app.release`，使用专用长期证书。
- 两渠道提供中英显示名称；namespace 保持不变，Activity、私有控制 receiver 和通知使用明确组件。
- 彼此的配置页面不进入 Agent 授权列表、观察或动作范围。启用另一渠道服务时阻止开始、归还或自动执行；同一时间使用一个服务。
- 正式私钥与 DPAPI 凭据位于仓库外的私有 ACL 目录。签名构建临时提供进程环境，关闭配置缓存和常驻 daemon；没有凭据时拒绝打包。
- 生产 Harness 状态机、模型动作协议、预算、提示词和数据合同没有修改。本轮没有模型调用，也未复制用户 API Key。
