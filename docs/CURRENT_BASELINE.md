## 保持的运行和数据边界

接管请求一到即关闭采集、屏蔽旧回复；已派发手机输入确认终态后才显示人工控制。人工期间不采集画面和轨迹。归还后重新观察；查证与恢复执行使用新的阶段对话，回退恢复原任务历史并从当前画面继续，不撤销人工操作。

Planner 最多两次实际尝试、只读查证最多一轮，首期只观察当前画面和等待刷新；第二次 Planner 判断完成直接结束，不追加 GUI done 或查证。只读最后一步 wait 耗尽额度而未合法 finish 时，按额度耗尽结束，不再调用 Planner。Harness 关闭时保持相同接管／归还通知、新观察和自动恢复策略，由原任务及自身历史继续。

暂时的请求／观察失败在执行策略 1.2 的有限次数内重新观察并让模型作新决策；不重放旧输入、不自动修正模型落点、不增加免费 GUI 步数。持续或不可恢复问题仍安全结束为 runtime_failure，不能承诺任何设备或网络故障下永不结束。模型声明完成只表示自动流程结束，独立任务结果另记。

截图仅在内存保留必要帧，不形成截图历史；Key 只在本机加密保存。任务原文按 [0.7.0 独立增量](EXPERIMENT_RECORDS_0.7.0.md)保留本地加密附件，不能把旧[数据边界快照](DATA_AND_LOGGING_BOUNDARIES.md)中的“任务正文仅内存”当作当前完整描述；无内容事件／导出仍不含任务正文、密钥、截图或原始模型回复。普通页面允许用户投屏，密钥编辑弹层仍防截屏，Agent 自身 App 的采集禁令仍有效。
