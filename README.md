# MobileHarness

[English](README.en.md) · 简体中文

让 GUI Agent 在 Android 手机上执行任务，并在需要时由你接管、操作和归还控制权。

当前版本：`0.9.0-dev`。首个公开安装包尚未发布；发布后从本仓库 [Releases](https://github.com/Rich-King395/MobileHarness/releases) 下载。项目许可证：[Apache-2.0](LICENSE)。

## ✨ 主要功能

- **手机独立运行**：安装和授权后即可使用；模型通过远程服务推理，日常运行不依赖电脑。
- **自由下达任务**：Agent 根据任务打开授权范围内的 App，无需每次指定初始 App。
- **随时主动接管**：通过贴边悬浮入口接管、归还或中止任务，通知栏提供备用入口。
- **可选 Harness**：归还后由 Planner 辅助判断剩余工作；关闭时，Agent 根据原任务与自身历史继续。
- **多模型配置**：保存多份命名配置，分别选择 GUI Agent 和 Planner 使用的服务与模型。
- **本地实验记录**：查看原任务、使用步数、Planner 调用和用户评价，筛选汇总并导出分析 CSV。
- **中英双语界面**。

## 🚀 开始使用

1. **安装与授权**：从 Releases 获取安装包后安装，按 App 提示手动开启 MobileHarness 无障碍服务，并允许通知以使用备用入口。
2. **配置模型**：在“模型”页添加名称、HTTPS 服务地址、模型名称和你自己的 API Key，分别选择 GUI Agent 与 Planner 的配置。
3. **选择授权范围**：首次在任务页选择允许 Agent 操作的 App；后续任务复用该范围，需要时再调整。
4. **下达任务**：输入目标，选择是否开启 Harness 和步数额度，确认必要截图将发送至所配置的远端服务后开始。默认 GUI 额度为 30 步。
5. **接管与归还**：展开悬浮入口并点击接管，等待状态从“暂停中”变为“人工”后操作手机；完成后点击归还。需要结束时点击中止。

首期每个任务支持 **一次有效接管与归还**。人工操作不消耗或重置 GUI 额度；Planner 调用单独记录。

## 📱 设备与模型

| 项目 | 当前范围 |
| --- | --- |
| Android | 最低 Android 11；主要实测 Google Pixel 4 / Android 13，其他设备仍待验证 |
| 推理 | 使用你配置的远端服务，安装包不附带模型服务或 API Key |
| 模型适配 | 当前主要验证 Qwen 3.8 MAX；其他模型需满足现有接口和动作协议要求 |

将配置命名为 GPT 或 Claude，不代表已支持它们的原生 API。GUI Agent 与 Planner 可以使用同一份配置，也可以分别选择。

## 📊 记录与结果

- 在“记录”页查看任务、GUI 用量、Planner 调用、结束原因和用户完成评价。
- 可为历史任务补充或修改评价，按 Harness 开关与评价筛选，并查看描述性汇总。
- 导出的分析 CSV 包含用量、评价、耗时及调用统计；不含任务原文、API Key、截图或人工操作轨迹。

模型表示结束与任务真正完成分别记录；用户评价也不是独立成功核验。不同任务的汇总不能直接证明 Harness 的效果。

## 🔒 数据边界

- API Key 仅在本机加密保存，不随安装包提供，也不进入普通日志或导出文件。
- 原任务在本机加密保存，便于回看；执行任务时，任务内容和必要截图会发送至你配置的模型服务。
- 截图仅按当前 GUI Agent／Planner 的需要在内存中暂存，不保留截图历史、不长期保存。
- 人工控制期间不采集画面或操作轨迹；归还后重新获取当前画面。
- 远端服务的数据保留与使用方式以服务商政策为准。请仅操作本人获授权的设备、App 和数据。
